# Contributing to toABify

Thank you for your interest in contributing to **toABify**!

Please read [DEVELOPMENT.md](DEVELOPMENT.md) for the full development guide,
including project layout, architecture, setup instructions, commands, and
the release process.

In short:

1. Fork & clone the repository.
2. Create a feature branch from `main`.
3. Run `ruff check .` and `ruff format --check .` before committing.
4. If you touch `dist/`, verify with `python scripts\verify_vendor.py`.
5. Open a Pull Request with a clear description.

All contributors are expected to follow the conventions documented in
`DEVELOPMENT.md`, including naming conventions and the list of known
deviations that must not be changed.
